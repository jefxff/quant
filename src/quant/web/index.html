    页面在做什么

    页面是一个只监听 127.0.0.1 的本地操作台。点击按钮后，浏览器把「操作 id + 参数」发给本机 Python 服务，服务端按白名单构造 python -m quant … 的 argv 列表执行，再原样返回命令、退出码、耗时与 stdout / stderr。命令不经过 shell，无法注入。

    启动与停止

    cd quant
./.venv/Scripts/python.exe -m quant ui
# 指定端口： -m quant ui --port 9000 --open
# Ctrl+C 停止

    端口被占用时自动向后顺延，实际地址以终端输出为准。

    等价的命令行

    ./.venv/Scripts/python.exe -m quant data update --source fixture \
  --pool hs300 --limit 5 --start 2022-01-04 --end 2022-12-30
./.venv/Scripts/python.exe -m quant backtest --strategy dual_ma --limit 5
./.venv/Scripts/python.exe -m quant paper run --date latest
./.venv/Scripts/python.exe -m quant report --run-id latest

    每个按钮都会显示实际执行的完整命令，可一键复制。

    为什么日期被改成年份后仍跑 2022？

    离线演示数据只有 2022-01-04 ~ 2022-12-30。按「禁止伪造行情」的约束，离线灌数据不会为你选的年份编造 K 线：服务端会把该动作钳制到演示区间并在回执里说明。「离线闭环」全程使用演示区间。想跑其他年份，请先用联网更新把真实行情写入本地库。

    退出码

    • 0 成功
    • 2 数据缺失
    • 3 网络失败
    • 4 校验失败
    • 1 其他错误
    • 124 执行超时

    安全与边界

    • 仅本机可访问，Host 不匹配直接 403
    • 操作 id 与参数均做白名单 / 正则校验
    • 同一时刻只允许一条命令
    • 报告文件读取做了目录逃逸校验
    • 不发送真实委托，不调用实盘接口

    界面

    正文与标题统一无衬线字体，命令和数字用等宽字体保证对齐；低饱和的黑白灰配一个主色，靠留白和字号建立层次。没有渐变、噪点、阴影和动画；深色主题可在右上角切换。
